# TFSA ETF Comparison Tool

This project is a Streamlit web app that helps South African investors compare the performance and costs of local and global ETFs and index funds. It also simulates long‑term growth inside a Tax‑Free Savings Account (TFSA).

## Features
- Compare ETFs by CAGR (Compound Annual Growth Rate) and TER (Total Expense Ratio).
- Simulate TFSA growth over 5–30 years with adjustable contribution frequency (annual, quarterly, monthly).
- Interactive dashboard with tables and charts.
- Live data pulled from Yahoo Finance.
